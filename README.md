# Crewdesk — All-in-One Agency Operations Platform (Agency OS)

> Run your whole agency from one connected system, not five tools and a spreadsheet.

Crewdesk is a modern, responsive single-page landing page and operations platform for digital agencies, dev shops, and software houses.

## 🚀 Highlights & Features

- **7 Operational Modules**:
  1. **Business Analysis Module**: Real project profit margins, billed revenue vs true developer costs.
  2. **Agency Overview Module**: Birds-eye view of agency progress, milestones, and employee momentum.
  3. **Attendance & Leave Module**: Daily 1-click punch in/out, late arrival flags, overtime approvals, and leaves.
  4. **Projects Module**: Category-wise client project organization and sprint deadlines.
  5. **Password Manager Module**: AES-256 encrypted client credentials vault with reveal audit logs.
  6. **Time Tracking Module**: Task-based timers and manual logging without timesheet fatigue.
  7. **Workload & Capacity Module**: Real-time developer capacity planning before allocating tasks.

- **4 Dedicated Role Dashboards**:
  - 🛡️ **Admin Dashboard**: Full operations command center with confidential margins.
  - 👥 **HR Dashboard**: Employee directory, onboarding, teams, and attendance.
  - 📋 **Project Manager Dashboard**: Task assignments, workload balancing, and sprints.
  - 💻 **Employee Dashboard**: Assigned tasks, time tracking, and 1-click attendance.

- **All-in-One Master Pricing & Savings Comparison Table**:
  - Live side-by-side pricing against **ClickUp Unlimited**, **ClickUp Business**, **HubSpot Starter**, and **Salesforce Starter**.
  - Interactive tabs for **Team of 10 (Starter)**, **Team of 25 (Growth)**, and **Team of 50 (Scale)**.
  - Real-time **Cash Saved** and **Founder Hours Reclaimed** (+18 to +50 hours/mo).
  - Global currency toggle for **PKR (₨)** and **USD ($)**.

- **Feature Comparison Matrix**:
  - Detailed breakdown of built-in ready features vs tools requiring weeks of DIY setup.

## 🌐 Instant Hosting & Deployment

Because this is a completely standalone `index.html` file with embedded CSS and modern JavaScript:
- **Vercel / Netlify / Cloudflare Pages**: Simply drag-and-drop or connect this repository.
- **GitHub Pages**: Go to `Settings -> Pages -> Deploy from Branch (main)` and your site is live immediately!
